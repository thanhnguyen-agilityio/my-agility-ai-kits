# my-agility-ai-kits

Internal to Agility. Do not share publicly.

A collection of AI kits from Agility: kits from client projects, my practice kits, and others. Each kit lives in its own folder under `kits/` and has its own README with install steps.

## Kits

| Kit | Source | What it is |
| --- | --- | --- |
| [`smoliv-relay`](kits/smoliv-relay/) | Project smoliv | Ticket to pull request with human gates. Claude Code skills and one command for a 7-step flow: grill, sync issue, plan, implement, review, address review, open PR. |

## Adding a kit

1. Put it in `kits/<kit-name>/` with a `README.md` that covers what it is, how to install it and where it came from.
2. Remove client data and secrets first.
3. Add a row to the table above.
